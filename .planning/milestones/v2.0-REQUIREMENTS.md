## v1 Requirements

### Device Management

- [x] **DEV-01**: Auto-detect best device (CUDA > MPS > CPU) with config override (`device: auto|cuda|mps|cpu`)
- [x] **DEV-02**: MPS-specific op alternatives for unsupported ops (torch.quantile via sort+index, torch.outer via broadcast, .contiguous() for MPS convolutions)
- [x] **DEV-03**: Device-aware AMP handling (autocast for MPS, DummyGradScaler routing, no GradScaler on MPS)
- [x] **DEV-04**: Device-aware memory cache cleanup between epochs (torch.cuda.empty_cache / torch.mps.empty_cache)

### Error Handling

- [x] **ERR-01**: Config validation at startup -- check all keys, types, ranges, cross-field consistency (dual_channel+input_channels, AMP+device) before data loading
- [x] **ERR-02**: NaN/Inf detection in loss and gradients -- check before backward, skip optimizer step on NaN, guard checkpoint saves, add NaN guard to DummyGradScaler
- [x] **ERR-03**: Data loading failure threshold -- fail loudly if >N% of data files fail to load
- [x] **ERR-04**: Graceful interrupt handling -- save emergency checkpoint on SIGINT/Ctrl+C during training

### Checkpoint & Resume

- [x] **CHK-01**: Full checkpoint resume -- restore model, optimizer, scheduler, scaler, epoch, best_val_loss, patience_counter, history from latest_checkpoint.pt
- [x] **CHK-02**: Atomic checkpoint writes -- write to temp file then rename to prevent corruption on crash
- [x] **CHK-03**: Embed normalization parameters in checkpoint file (self-contained, not dependent on metadata.json)
- [x] **CHK-04**: Cross-device resume -- load CUDA checkpoint on MPS/CPU with manual optimizer state tensor device remapping

### Data Loading

- [x] **DAT-01**: Lazy/memory-mapped data loading via np.load(mmap_mode='r') with worker-local file descriptor handling for DataLoader num_workers > 0
- [x] **DAT-02**: Conditional pin_memory -- True for CUDA only, False for MPS/CPU
- [x] **DAT-03**: Fork-safe augmentation -- fix np.random in DataLoader workers via worker_init_fn or torch.rand

### Memory Optimization

- [x] **MEM-01**: Welford's online algorithm for MC Dropout uncertainty estimation -- O(1) memory instead of O(N) sample stacking
- [x] **MEM-02**: Device-aware epoch-boundary cache cleanup (torch.cuda.empty_cache / torch.mps.empty_cache after validation)
- [x] **MEM-03**: SSIM loss optimization for large spatial tensors (cache Gaussian kernels, consider tiling)

### Tech Debt Cleanup

- [x] **TDC-01**: Delete legacy ConvLSTM.py (698 lines) from project root -- organized modules are authoritative
- [x] **TDC-02**: Fix inference.py to use utils/device.py get_device() instead of hardcoded 'cuda' string
- [x] **TDC-03**: Reproducible seeding -- set torch/numpy/python seeds at startup, replace np.random.rand with torch.rand in teacher forcing

### Test Coverage

- [x] **TST-01**: Model forward pass shape tests for all config combinations (single/dual channel, various t_in/t_out)
- [x] **TST-02**: Loss function unit tests (L1, SSIM, MS-SSIM, composite loss, WeightedMAE, edge cases including NaN input)
- [x] **TST-03**: Checkpoint save/load roundtrip test -- verify identical output before save and after load, including cross-device
- [x] **TST-04**: Data pipeline integration test -- loading, normalization, splitting, augmentation produces valid tensors
- [x] **TST-05**: Device compatibility smoke test -- forward pass on CPU (and MPS if available) with synthetic data
- [x] **TST-06**: Config validation tests -- bad configs rejected with clear messages, good configs pass
