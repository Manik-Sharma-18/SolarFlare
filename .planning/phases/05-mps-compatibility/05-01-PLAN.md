<objective>
Create MPS-safe op alternatives module and rework SSIM loss for MPS correctness, kernel caching, and large-tensor tiling.

Purpose: MPS grouped conv2d has known correctness bugs producing silently wrong SSIM results. torch.outer may also be problematic. This plan creates device-dispatched wrappers and reworks SSIM to use channel-loop fallback on MPS, cache Gaussian kernels, and tile large spatial inputs.

Output: New `utils/mps_ops.py` with safe_outer and safe_quantile; reworked `training/losses.py` with kernel caching, channel-loop MPS fallback, and tiled SSIM.
</objective>

Create `utils/mps_ops.py` with:

1. Module-level `_mps_ops_logged = False` flag for one-time INFO log.

2. `safe_outer(a, b)`:
   - If device is MPS: use `a.unsqueeze(-1) * b.unsqueeze(0)` (broadcast multiplication).
   - If CUDA/CPU: use `torch.outer(a, b)` (native op).
   - On first MPS call, log once at INFO: "MPS device detected: using alternative ops for correctness".

3. `safe_quantile(tensor, q, dim)`:
   - If device is MPS: sort along dim, compute index as `q * (size - 1)`, use floor/ceil interpolation to match torch.quantile behavior. Return result on same device.
   - If CUDA/CPU: use `torch.quantile(tensor, q, dim=dim)`.

4. `is_mps(tensor_or_device)` helper:
   - Accept either a torch.Tensor or torch.device.
   - Return True if device type is "mps".

Add `mps_ops` to `utils/__init__.py` imports.

  <name>Task 2: Rework SSIM in losses.py with kernel caching, MPS channel-loop, and tiling</name>
  <files>training/losses.py</files>
  <action>
Modify `training/losses.py`:

1. **Gaussian kernel caching:**
   - Add module-level `_KERNEL_CACHE = {}` dict.
   - Modify `gaussian_kernel()` to check cache with key `(size, sigma, str(device))`. If cached, return cached kernel. Otherwise compute, cache, and return.
   - Replace `g.outer(g)` with `safe_outer(g, g)` from `utils.mps_ops`.

2. **Channel-loop SSIM on MPS:**
   - In `ssim()`, after creating the window, check `is_mps(pred.device)`.
   - If MPS: loop over channels (0 to C-1), run `F.conv2d` with `groups=1` on each single-channel slice, concatenate results. Do this for all 5 conv2d calls (mu1, mu2, sigma1_sq, sigma2_sq, sigma12).
   - If CUDA/CPU: keep existing `groups=pred.size(1)` grouped convolution (unchanged behavior).
   - Extract the conv2d calls into a helper `_ssim_conv2d(input_tensor, window, C, padding, device)` that handles the dispatch internally to keep ssim() readable.

3. **Tiled SSIM for large spatial tensors:**
   - Add a `ssim_tiling_threshold` parameter to `ssim()` with default 256.
   - Before computing SSIM, check if `H > threshold or W > threshold`.
   - If so: split into tiles of size `threshold` with overlap of 16 pixels. Compute SSIM per tile. Average all tile SSIM values (weighted by tile area, excluding overlap regions in the average to avoid double-counting).
   - If not: compute normally (existing path).
   - The `CompositeLoss` class should accept `ssim_tiling_threshold` in its `__init__` and pass it through to ssim/ms_ssim calls.

4. **Update get_loss_function:**
   - Pass `ssim_tiling_threshold` from config through to `CompositeLoss`.
   - Config key: `ssim_tiling_threshold` under `loss` section, default 256.

Do NOT change WeightedMAELoss or the overall CompositeLoss structure. Only SSIM-related code changes.
