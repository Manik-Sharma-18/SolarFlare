<task type="auto">
  <name>Task 1: Rewrite utils/device.py with cross-platform device API</name>
  <files>utils/device.py</files>
  <action>
  Rewrite `utils/device.py` completely. Replace the current `get_device(use_cuda: bool)` API with the following functions:

  **`resolve_device(device_config: str) -> torch.device`**
  - Accepts: `"auto"`, `"cuda"`, `"mps"`, `"cpu"`
  - `"auto"` detection priority: CUDA > MPS > CPU
    - Check `torch.cuda.is_available()` first
    - Check `torch.backends.mps.is_available()` second
    - Fall back to CPU
  - If a forced device (e.g. `"mps"`) is unavailable, raise `RuntimeError` with a clear message like `"Device 'mps' requested but MPS is not available on this system"`. Do NOT silently fall back.
  - Print a single startup log line: `"Using device: mps (Apple M2 Pro)"` for MPS, `"Using device: cuda (NVIDIA RTX 3050, 4.0 GB)"` for CUDA, `"Using device: cpu"` for CPU.
    - For CUDA: include `torch.cuda.get_device_name(0)` and VRAM in GB
    - For MPS: include `platform.processor()` to show chip name
    - For CPU: just `"Using device: cpu"`
  - Return `torch.device(...)` object

  **`get_amp_context(use_amp: bool, device: torch.device)`**
  - If `use_amp` is True and device is CUDA: return `torch.amp.autocast(device_type='cuda')`
  - If `use_amp` is True and device is MPS: return `torch.amp.autocast(device_type='mps')`
  - If `use_amp` is True and device is CPU: return `torch.amp.autocast(device_type='cpu')`
  - If `use_amp` is False: return `nullcontext()`

  **`get_grad_scaler(use_amp: bool, device: torch.device)`**
  - If `use_amp` is True and device is CUDA: return `torch.amp.GradScaler()`
  - Otherwise (MPS, CPU, or use_amp=False): return `_DummyGradScaler()`
  - Keep the existing `_DummyGradScaler` class unchanged (it works correctly)

  **`clear_device_cache(device: torch.device)`**
  - If device is CUDA: call `torch.cuda.empty_cache()`
  - If device is MPS: call `torch.mps.empty_cache()`
  - If device is CPU: no-op (just return)

  Keep `import platform` at top for the MPS chip name detection. Remove the old `get_device(use_cuda)` function entirely -- do not keep it for backward compatibility (callers will be updated in Plan 02).

  Also update `utils/__init__.py` to export the new function names: `resolve_device` instead of `get_device`, plus `clear_device_cache`.
  </action>
  <verify>
  Run `python -c "from utils.device import resolve_device, get_amp_context, get_grad_scaler, clear_device_cache; d = resolve_device('auto'); print(d); print(type(get_grad_scaler(True, d)))"` -- should print the detected device and scaler type without errors.

  Run `python -c "from utils.device import resolve_device; resolve_device('cuda')"` on a Mac -- should raise RuntimeError about CUDA unavailability, not silently fall back.
  </verify>
  <done>
  - `resolve_device('auto')` detects best device with CUDA > MPS > CPU priority
  - `resolve_device('mps')` on non-MPS machine raises RuntimeError
  - `get_grad_scaler(True, mps_device)` returns DummyGradScaler (not real GradScaler)
  - `get_amp_context(True, mps_device)` returns autocast with device_type='mps'
  - `clear_device_cache(device)` calls correct cache cleanup per device type
  - Old `get_device()` function is removed
  </done>
