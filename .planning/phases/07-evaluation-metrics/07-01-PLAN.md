  <implementation>
    Add all new metric functions to utils/metrics.py following the existing pattern of pure, stateless functions.

    Key implementation details:
    1. CSI = TP / (TP + FP + FN), guard denom == 0
    2. HSS = 2*(TP*TN - FP*FN) / ((TP+FN)*(FN+TN) + (TP+FP)*(FP+TN)), guard denom == 0
    3. accumulate_contingency: binary_pred = (pred.abs() > threshold).long(), iterate over T dimension, return list of (tp, fp, fn, tn) tuples as ints
    4. compute_persistence_prediction: X_in[:, :output_channels, -1:, :, :].expand(-1, -1, T_out, -1, -1)
    5. compute_persistence_skill: (1 - model_mae / persistence_mae) * 100, guard persistence_mae < 1e-8
    6. compute_ssim_per_timestep: loop over T, call ssim(pred[:,:,t], target[:,:,t], data_range=data_range, size_average=True)
    7. compute_peak_flux_error: per timestep, pred[:,:,t].amax(dim=(-2,-1)) vs target[:,:,t].amax(dim=(-2,-1)), abs diff, mean over batch
    8. compute_temporal_variation_ratio: mean(abs(pred[:,:,1:] - pred[:,:,:-1])) / mean(abs(target[:,:,1:] - target[:,:,:-1])), guard target_diffs < 1e-8
    9. compute_rmse_per_timestep: for each t, sqrt(mean((pred[:,:,t] - target[:,:,t])^2))
    10. compute_correlation_per_timestep: for each t, pearson on flattened pred[:,:,t] vs target[:,:,t]

    Import ssim from training.losses for SSIM computation. All other functions use only torch operations.
  </implementation>
