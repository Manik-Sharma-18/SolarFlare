<task type="auto">
  <name>Task 2: Add graceful shutdown with emergency checkpoint on SIGINT/SIGTERM</name>
  <files>training/trainer.py, main.py</files>
  <action>
Modify `train_model()` in `training/trainer.py`:

1. **Signal handler setup** — at the start of `train_model()`, before the training loop:
   ```python
   import signal
   import sys

   # Graceful shutdown state
   _shutdown_requested = False
   _force_quit = False

   def _shutdown_handler(signum, frame):
       nonlocal _shutdown_requested, _force_quit
       if _shutdown_requested:
           # Second signal = force quit
           print("\nForce quit requested. Exiting immediately without saving.")
           sys.exit(1)
       _shutdown_requested = True
       sig_name = signal.Signals(signum).name
       print(f"\n{sig_name} received. Saving emergency checkpoint before exit...")
       print("(Press Ctrl+C again to force quit immediately)")

   old_sigint = signal.signal(signal.SIGINT, _shutdown_handler)
   old_sigterm = signal.signal(signal.SIGTERM, _shutdown_handler)
   ```

2. **Check shutdown flag in training loop** — after each epoch (after the early stopping check), add:
   ```python
   if _shutdown_requested:
       # Save emergency checkpoint
       emergency_path = save_dir / f"EMERGENCY_{checkpoint_name}"
       emergency_dict = {
           'epoch': epoch,
           'model_state_dict': model.state_dict(),
           'optimizer_state_dict': optimizer.state_dict(),
           'val_loss': val_loss,
           'config': config,
           'emergency': True,  # Flag marking this as interrupted save
           'reason': 'user_interrupt'
       }
       if scheduler_enabled:
           emergency_dict['scheduler_state_dict'] = scheduler.state_dict()
       torch.save(emergency_dict, emergency_path)
       print(f"\nEmergency checkpoint saved to: {emergency_path}")
       print(f"  Epoch: {epoch}, Val Loss: {val_loss:.6f}")
       # Restore original signal handlers before exiting
       signal.signal(signal.SIGINT, old_sigint)
       signal.signal(signal.SIGTERM, old_sigterm)
       sys.exit(0)
   ```

3. **Also check shutdown in inner loop** — add a check at the start of each batch iteration in `train_epoch()`. This requires passing the shutdown state. Rather than complex threading, use a simpler approach: make `_shutdown_requested` a mutable container accessible to train_epoch. Use a dict or class:

   Actually, the cleaner approach: only check between epochs in `train_model()`. An epoch on batch_size=1 data finishes fast enough. The signal handler sets the flag, the current epoch completes, then shutdown triggers. This avoids passing shutdown state through train_epoch.

4. **Restore signal handlers** — in a try/finally block around the training loop:
   ```python
   try:
       for epoch in range(1, epochs + 1):
           ...
   finally:
       signal.signal(signal.SIGINT, old_sigint)
       signal.signal(signal.SIGTERM, old_sigterm)
   ```

5. **Emergency checkpoint naming convention:** `EMERGENCY_{checkpoint_name}` (e.g., `EMERGENCY_best_model.pt`). The `'emergency': True` metadata flag lets downstream code identify these.

6. **Handle NaNLossError from train_epoch**: In `train_model()`, wrap the `train_epoch()` call in try/except for `NaNLossError`. On catch, save an emergency checkpoint with `'reason': 'nan_loss_abort'` and re-raise.

7. **In main.py**, wrap `run_training()` call with a try/except for `SystemExit` to handle the graceful shutdown exit cleanly (avoid traceback on Ctrl+C):
   ```python
   try:
       run_training(config)
   except SystemExit as e:
       sys.exit(e.code)
   ```
