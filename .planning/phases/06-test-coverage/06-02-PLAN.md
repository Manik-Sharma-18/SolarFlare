  <name>Task 1: Write loss function unit tests</name>
  <files>tests/test_losses.py</files>
  <action>
Create `tests/test_losses.py` testing all loss functions from `training/losses.py` (TST-02).

All tests use CPU tensors with small spatial dims (e.g., 32x32) and batch_size=1-2.

**SSIM tests:**
1. `test_ssim_identical_inputs()`: `ssim(x, x)` returns value close to 1.0 (atol=0.01). Use x = torch.rand(1, 1, 32, 32).
2. `test_ssim_different_inputs()`: `ssim(x, y)` for random x, y returns value in [0, 1] and < 1.0.
3. `test_ssim_symmetry()`: `ssim(x, y) == ssim(y, x)` (atol=1e-6).
4. `test_ssim_nan_input_no_crash()`: `ssim(x_with_nans, y)` does not raise an exception (may return NaN, which is acceptable).

**MS-SSIM tests:**
5. `test_ms_ssim_identical_inputs()`: `ms_ssim(x, x)` returns value close to 1.0 (atol=0.05). Use x with spatial >= 64x64 (needs multiple downsampling levels -- use 64x64 minimum).
6. `test_ms_ssim_returns_finite()`: `ms_ssim(x, y)` for random x, y returns `torch.isfinite()`.

**Gaussian kernel tests:**
7. `test_gaussian_kernel_shape()`: `gaussian_kernel(11, 1.5, 'cpu')` returns shape (11, 11).
8. `test_gaussian_kernel_sums_to_one()`: kernel values sum to ~1.0 (atol=0.01).
9. `test_gaussian_kernel_caching()`: Call twice with same args, verify `kernel1 is kernel2` (same object). Clear `_KERNEL_CACHE` after test.

**WeightedMAE tests:**
10. `test_weighted_mae_zero_error()`: For pred == target, loss is 0 (or very close to 0; note: base_weight still applies so the loss is base_weight * 0 = 0).
11. `test_weighted_mae_extreme_higher_weight()`: Create target with one extreme region (value=10) and one normal region (value=0.1). Compute loss for uniform error. Verify loss > F.l1_loss (the weighting makes it higher).

**CompositeLoss tests:**
12. `test_composite_loss_returns_scalar()`: `CompositeLoss()(pred, target)` returns a 0-dim tensor.
13. `test_composite_loss_returns_finite()`: Output is `torch.isfinite()`.
14. `test_composite_loss_components()`: With `return_components=True`, returns dict with keys 'total', 'l1', 'ssim', 'ssim_val', 'extreme'.
15. `test_composite_loss_5d_input()`: Pass 5D tensors (B, C, T, H, W) -- verify it handles temporal flattening correctly and returns finite loss. Use shape (1, 1, 2, 32, 32).

**get_loss_function tests:**
16. `test_get_loss_function_l1()`: Returns nn.L1Loss instance.
17. `test_get_loss_function_composite()`: Returns CompositeLoss instance.
18. `test_get_loss_function_weighted()`: Returns WeightedMAELoss instance.
19. `test_get_loss_function_unknown_raises()`: `get_loss_function({'type': 'mse'})` raises ValueError.

**Important:** After tests that modify `_KERNEL_CACHE`, clear it to avoid test pollution. Use a fixture or teardown.
  </action>

Run `pytest tests/test_losses.py -v --tb=short` -- all tests pass.

Create `tests/test_model.py` testing SolarFluxPredictor forward pass (TST-01, TST-05).

Use tiny model configs to keep tests fast: channels=[4,8,16], kernel_size=3, downsample_input=False. Spatial dims 32x32 (sufficient for convolutions). batch_size=1.

**Shape tests (parametrized where possible):**
1. `test_forward_basic_shape()`: input_channels=1, output_channels=1, t_in=4, t_out=2. Input (1,1,4,32,32) -> output (1,1,2,32,32).
2. `test_forward_dual_channel()`: input_channels=2, output_channels=1, t_in=4, t_out=2. Input (1,2,4,32,32) -> output (1,1,2,32,32). Verifies multi-channel input with single-channel output.
3. `test_forward_different_t_out()`: Use `@pytest.mark.parametrize("t_out", [1, 3, 5])`. Verify output temporal dim matches t_out.
4. `test_forward_different_t_in()`: Use `@pytest.mark.parametrize("t_in", [2, 6, 10])`. Verify model processes different input lengths.
5. `test_forward_with_downsample()`: Set downsample_input=True, use spatial 64x64 (needs even dims for stride-2). Verify output shape (1, 1, t_out, 64, 64).
6. `test_forward_output_is_finite()`: Verify `torch.isfinite(output).all()` for a basic forward pass with random input.
7. `test_forward_with_teacher_forcing()`: Pass y_true and teacher_forcing_ratio=0.5, verify output shape unchanged.
8. `test_forward_with_dropout()`: Set dropout_rate=0.1, verify output shape. Run twice -- outputs should differ (dropout randomness). Use `model.train()`.
9. `test_count_parameters()`: Verify `model.count_parameters()` returns a positive integer.
10. `test_model_to_device()`: `model.to(torch.device('cpu'))` works without error, parameters are on CPU.

**Device smoke test (TST-05):**
11. `@pytest.mark.mps test_forward_on_mps()`: Create model and input on MPS, run forward pass, verify output is finite and correct shape. Only runs on MPS hardware.

All models should be created inside the test function (not as fixtures) to avoid memory accumulation.
