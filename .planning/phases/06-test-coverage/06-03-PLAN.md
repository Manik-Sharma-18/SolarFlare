  <name>Task 1: Write checkpoint roundtrip tests</name>
  <files>tests/test_checkpoint.py</files>
  <action>
Create `tests/test_checkpoint.py` testing checkpoint save/load from `utils/checkpoint.py` (TST-03).

Use a real but tiny SolarFluxPredictor: input_channels=1, output_channels=1, t_out=2, channels=[4,8,16], kernel_size=3, downsample_input=False, dropout_rate=0.0.

**Roundtrip tests:**
1. `test_checkpoint_roundtrip_identical_output(tmp_path)`:
   - Create model, optimizer (Adam), scheduler=None, scaler=DummyGradScaler
   - Run forward pass on fixed input `x = torch.randn(1, 1, 4, 32, 32)`, save output_before
   - Call `save_checkpoint(filepath, epoch=5, model=model, optimizer=optimizer, scheduler=None, scaler=scaler, best_val_loss=0.5, patience_counter=2, normalization_params={'method': 'asinh', 'scale': 1.0}, config={'device': 'cpu'}, history={'train_loss': [1.0, 0.5]})`
   - Create NEW model with same architecture, NEW optimizer
   - Call `load_checkpoint_for_resume(filepath, model2, optimizer2, scheduler=None, scaler=scaler2, device=torch.device('cpu'))`
   - Run forward pass on same input x, get output_after
   - Assert `torch.allclose(output_before, output_after, atol=1e-6)`

2. `test_checkpoint_roundtrip_state_restored(tmp_path)`:
   - Save checkpoint at epoch=5, best_val_loss=0.123, patience_counter=3
   - Load and verify returned (start_epoch=6, best_val_loss=0.123, patience_counter=3)

3. `test_checkpoint_roundtrip_normalization_params(tmp_path)`:
   - Save with normalization_params={'method': 'asinh', 'asinh_softening': 0.005, 'scale': 3.0}
   - Load checkpoint, verify normalization_params preserved exactly

**Atomic save tests:**
4. `test_atomic_save_creates_file(tmp_path)`:
   - Call `_atomic_save({'test': 1}, tmp_path / 'test.pt')`
   - Verify file exists
   - Load with torch.load, verify contents

5. `test_atomic_save_no_temp_files_left(tmp_path)`:
   - After _atomic_save, verify no `.tmp_ckpt_*` files remain in tmp_path

**Error handling tests:**
6. `test_load_checkpoint_missing_file()`:
   - `load_checkpoint('/nonexistent/path.pt')` raises FileNotFoundError

7. `test_load_checkpoint_version_mismatch(tmp_path)`:
   - Save a dict with `checkpoint_version=999` using torch.save
   - `load_checkpoint(filepath)` raises RuntimeError with "version mismatch"

8. `test_checkpoint_architecture_mismatch(tmp_path)`:
   - Save checkpoint from model with channels=[4,8,16]
   - Try to load into model with channels=[8,16,32]
   - `load_checkpoint_for_resume()` raises RuntimeError with "Architecture mismatch"

**Config diff tests:**
9. `test_config_diff_detects_changes()`:
   - Call `_diff_configs({'lr': 0.001}, {'lr': 0.0001})`
   - Verify diff contains 'lr' and both values

10. `test_config_diff_empty_for_identical()`:
   - `_diff_configs({'a': 1}, {'a': 1})` returns empty list

**Import `_atomic_save` and `_diff_configs` directly** -- they're private but testing them explicitly is cleaner than testing indirectly through save_checkpoint.

  <action>
Create `tests/test_data_pipeline.py` testing data pipeline from `solarflare_data/dataset.py` (TST-04).

Tests create synthetic .npy files using `tmp_path` and exercise the real mmap loading path.

**Helper fixture** (local to this file):
- `sample_npy_files(tmp_path)`: Create 3 synthetic .npy files, each shape (20, 32, 32) with random float32 values in [0, 10]. Save with np.save. Return list of file paths.

**Dataset loading tests:**
1. `test_dataset_len_matches_index(sample_npy_files)`:
   - Create index with `build_index()` for t_in=4, t_out=2, stride=1
   - Create SolarFluxDataset with that index
   - Verify `len(dataset) == len(index)`

2. `test_dataset_getitem_shape(sample_npy_files)`:
   - Get sample via `dataset[0]`
   - Verify X_in shape is (1, 4, 32, 32) and Y_out shape is (1, 2, 32, 32)
   - Verify info is a tuple of (int, int)

3. `test_dataset_getitem_dual_channel(sample_npy_files)`:
   - Create dataset with dual_channel=True, extreme_threshold=5.0
   - Get sample, verify X_in shape is (2, 4, 32, 32) and Y_out shape is (2, 2, 32, 32)

4. `test_dataset_values_are_finite(sample_npy_files)`:
   - Get sample, verify `torch.isfinite(X_in).all()` and `torch.isfinite(Y_out).all()`

5. `test_dataset_returns_none_on_bad_file(tmp_path)`:
   - Create a .npy file that's too short (shape (3, 32, 32), less than t_in+t_out=6)
   - Build index manually with a valid-looking entry that will fail at read time
   - Or: create a corrupt file (write random bytes, save as .npy)
   - Verify `dataset[0]` returns None

**build_index tests:**
6. `test_build_index_count_no_augmentation(sample_npy_files)`:
   - build_index with augmentation="none", stride=1, t_in=4, t_out=2
   - Each file has 20 timesteps, max_start = 20 - 4 - 2 + 1 = 15 windows
   - Total = 3 files * 15 = 45
   - Verify len(index) == 45

7. `test_build_index_balanced_augmentation_multiplies(sample_npy_files)`:
   - build_index with augmentation="balanced" for split="train"
   - Balanced has 3 aug codes (NONE, HFLIP, VFLIP)
   - Total = 3 * 15 * 3 = 135
   - Verify len(index) == 135

8. `test_build_index_val_split_no_augmentation(sample_npy_files)`:
   - build_index with augmentation="balanced" for split="val"
   - Val split never gets augmentation
   - Verify count == 45 (no multiplication)

9. `test_build_index_stride(sample_npy_files)`:
   - build_index with stride=2, augmentation="none"
   - Windows at positions 0, 2, 4, 6, 8, 10, 12, 14 -> 8 per file
   - Total = 3 * 8 = 24

**Augmentation tests:**
10. `test_augmentation_hflip()`:
    - Create data array (2, 4, 4) with known values
    - Apply `SolarFluxDataset._apply_augmentation(data, AUG_HFLIP)`
    - Verify horizontal flip (axis=2 reversed)

11. `test_augmentation_none_is_copy()`:
    - Apply AUG_NONE, verify result == original but is a different object (`is not`)

**Normalization tests:**
12. `test_normalization_asinh_on_the_fly(sample_npy_files)`:
    - Create dataset with norm_params={'asinh_softening': 0.005, 'scale': 3.0}, norm_method='asinh'
    - Get sample, verify values are normalized (different from raw, finite)

13. `test_normalization_linear_on_the_fly(sample_npy_files)`:
    - Create dataset with norm_params={'center': 5.0, 'scale': 2.5}, norm_method='linear'
    - Get sample, verify mean of values is roughly centered near 0

For the `sample_npy_files` fixture, also return a `file_assignments` dict mapping all 3 file indices to "train" split so build_index can use it directly.
