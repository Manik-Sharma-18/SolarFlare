**tests/test_device.py** -- Tests for `utils/device.py` (TST-05):

5. `test_resolve_device_unavailable_mps_raises_runtime()`: Same pattern for MPS. Skip if MPS IS available.

8. `test_get_grad_scaler_cpu()`: `get_grad_scaler(False, torch.device('cpu'))` returns `_DummyGradScaler`
9. `test_get_grad_scaler_amp_cpu()`: `get_grad_scaler(True, torch.device('cpu'))` returns `_DummyGradScaler` (not real scaler)
10. `test_dummy_grad_scaler_scale_passthrough()`: Create a dummy loss tensor, verify `scaler.scale(loss) is loss`
11. `test_dummy_grad_scaler_step_calls_optimizer()`: Create a simple model+optimizer, do a forward+backward, call `scaler.step(optimizer)`, verify params changed (compare before/after)
12. `test_dummy_grad_scaler_update_noop()`: `scaler.update()` does not raise
13. `test_dummy_grad_scaler_skips_nan_grads()`: Create param with NaN grad, verify `scaler.step()` does NOT call `optimizer.step()` (params unchanged)
14. `test_clear_device_cache_cpu_noop()`: `clear_device_cache(torch.device('cpu'))` does not raise
15. `@pytest.mark.mps test_resolve_device_mps()`: `resolve_device('mps')` returns `torch.device('mps')` -- only runs on MPS hardware
