<objective>
Wire per-component loss logging into the training loop (LOSS-07): modify train_epoch to capture and return individual loss component averages, extend train_model history dict with 6 component keys, add compact console summary per epoch, and add multi-panel loss breakdown visualization.

Purpose: Without per-component logging, it is impossible to diagnose which loss term is driving training behavior, whether components are balanced, or if one term dominates. This is the observability layer for the new loss system.

Output: Modified trainer.py with component capture/logging, extended visualization.py with loss breakdown plot.
</objective>
