<task type="auto">
  <name>Task 1: Implement save_checkpoint with atomic writes and CPU tensor normalization</name>
  <files>utils/checkpoint.py</files>
  <action>
Create `utils/checkpoint.py` with these components:

**Constants:**
- `CHECKPOINT_VERSION = 1` -- integer, bumped on format changes

**Private helpers:**
- `_move_optimizer_state_to_cpu(optimizer_state_dict)` -- recursively walk the optimizer state dict and call `.cpu()` on every tensor found. AdamW has a flat per-parameter structure, but use recursive walking for safety (handle nested dicts and lists).
- `_atomic_save(state_dict, filepath)` -- write checkpoint atomically:
  1. `filepath.parent.mkdir(parents=True, exist_ok=True)`
  2. Create `tempfile.NamedTemporaryFile(dir=filepath.parent, prefix='.tmp_ckpt_', suffix='.pt', delete=False)`
  3. `torch.save(state_dict, tmp_path)`
  4. Open tmp_path in 'rb' mode and `os.fsync(f.fileno())` to flush to disk
  5. `os.replace(tmp_path, str(filepath))` for atomic rename
  6. In except block: `os.unlink(tmp_path)` then re-raise
  7. Close the temp file handle in finally block

**Public function:**
- `save_checkpoint(filepath, epoch, model, optimizer, scheduler, scaler, best_val_loss, patience_counter, normalization_params, config, history, emergency=False, emergency_reason=None)` -- builds the checkpoint dict and calls `_atomic_save()`.

Checkpoint dict schema (exact keys):
```python
{
    'checkpoint_version': CHECKPOINT_VERSION,
    'epoch': epoch,
    'model_state_dict': {k: v.cpu() for k, v in model.state_dict().items()},
    'optimizer_state_dict': optimizer.state_dict(),  # CPU-moved below
    'scheduler_state_dict': scheduler.state_dict() if scheduler else None,
    'scaler_state_dict': scaler.state_dict() if hasattr(scaler, 'state_dict') and not isinstance(scaler, DummyGradScaler) else None,
    'best_val_loss': best_val_loss,
    'patience_counter': patience_counter,
    'normalization_params': normalization_params,
    'config': config,
    'history': history,
    'emergency': emergency,
    'emergency_reason': emergency_reason,
}
```

For scaler detection: import `DummyGradScaler` from `utils.device` to check if the scaler is real. Only save `scaler.state_dict()` for real GradScaler (CUDA AMP). The DummyGradScaler has no meaningful state.

After building the dict, call `_move_optimizer_state_to_cpu()` on the optimizer_state_dict, then `_atomic_save()`.

Log at INFO level: `"Checkpoint saved: {filepath} (epoch {epoch}, val_loss {best_val_loss:.6f})"`
If emergency: `"Emergency checkpoint saved: {filepath} (reason: {emergency_reason})"`

<task type="auto">
  <name>Task 2: Implement load_checkpoint with version validation, device remapping, architecture mismatch detection, and config diffing</name>
  <files>utils/checkpoint.py</files>
  <action>
Add to `utils/checkpoint.py`:

**Private helpers:**
- `_diff_configs(saved_config, current_config, path="")` -- recursively compare two config dicts. Returns a list of human-readable diff strings like `"  training.lr: 0.001 -> 0.0001"`. Handle: keys in one but not other, value differences, nested dicts.

- `_check_state_dict_compatibility(model, state_dict)` -- compare model's state_dict keys with checkpoint's state_dict keys. If there are missing or unexpected keys, raise RuntimeError with a formatted diff showing:
  - Missing keys (in model but not checkpoint) with `-` prefix
  - Unexpected keys (in checkpoint but not model) with `+` prefix
  - Count of each

- `_optimizer_to_device(optimizer, device)` -- after loading optimizer state, move all tensors to target device. Iterate `optimizer.state.values()`, then iterate each state's items, and call `.to(device)` on any tensor.

**Public function:**
- `load_checkpoint(filepath, device=None)` -- load and validate a checkpoint:
  1. Check `filepath.exists()` -- raise `FileNotFoundError(f"Checkpoint not found: {filepath}")` if missing
  2. `torch.load(filepath, map_location='cpu', weights_only=False)`
  3. Check `checkpoint_version` -- if missing or != CHECKPOINT_VERSION, raise `RuntimeError` with clear message showing file version vs expected
  4. Return the checkpoint dict (caller applies it to model/optimizer/scheduler)

- `load_checkpoint_for_resume(filepath, model, optimizer, scheduler, scaler, device, current_config=None)` -- high-level resume function:
  1. Call `load_checkpoint(filepath, device)` to get validated dict
  2. Call `_check_state_dict_compatibility(model, checkpoint['model_state_dict'])` to fail on architecture mismatch
  3. `model.load_state_dict(checkpoint['model_state_dict'])`
  4. `model.to(device)`
  5. `optimizer.load_state_dict(checkpoint['optimizer_state_dict'])`
  6. Call `_optimizer_to_device(optimizer, device)`
  7. If scheduler and checkpoint has `scheduler_state_dict`: `scheduler.load_state_dict(...)`
  8. If scaler and checkpoint has `scaler_state_dict` and scaler is not DummyGradScaler: `scaler.load_state_dict(...)`
  9. If `current_config` provided, call `_diff_configs(checkpoint['config'], current_config)` and log each diff as a WARNING: `"Config changed since checkpoint: {diff}"`
  10. Log the saved device vs current device at INFO if different: `"Loading checkpoint trained on {saved_device}, resuming on {device}"`
  11. Return tuple: `(start_epoch, best_val_loss, patience_counter, history, normalization_params)` where start_epoch = checkpoint['epoch'] + 1

- `load_checkpoint_for_inference(filepath, device=None)` -- for inference use:
  1. If device is None, call `resolve_device('auto')` (import from utils.device)
  2. Call `load_checkpoint(filepath)` to get validated dict
  3. Log device remapping if saved device differs from target
  4. Return `(checkpoint, device)` -- caller builds model from checkpoint's config and loads weights

**Update `utils/__init__.py`** to export `save_checkpoint`, `load_checkpoint`, `load_checkpoint_for_resume`, `load_checkpoint_for_inference` if the pattern is to export from utils. Check what's currently exported and follow the same pattern.
