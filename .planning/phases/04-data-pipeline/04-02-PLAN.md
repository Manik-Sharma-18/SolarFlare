**New `assign_files_to_splits` function:**
```python
def assign_files_to_splits(
    file_paths: List[Path],
    split_ratios: List[float],  # [train, test, val] e.g. [0.7, 0.2, 0.1]
    seed: int
) -> Dict[str, List[int]]:
```
- Validate ratios sum to ~1.0 (within 0.01 tolerance)
- Create index list `[0, 1, ..., N-1]` and shuffle with `rng = random.Random(seed); rng.shuffle(indices)`
- Compute split boundaries: `n_train = round(len * ratios[0])`, `n_test = round(len * ratios[1])`, `n_val = len - n_train - n_test` (remainder to val, but if that makes val negative, give extra to train)
- Return `{"train": indices[:n_train], "test": indices[n_train:n_train+n_test], "val": indices[n_train+n_test:]}`
- Log which files go to which split

**Rewrite `load_and_prepare_data`:**
New signature:
```python
def load_and_prepare_data(
    data_dir: str,
    t_in: int = 8,
    t_out: int = 3,
    split_ratios: List[float] = None,  # default [0.7, 0.2, 0.1]
    stride: int = 1,
    norm_method: str = "robust",
    norm_config: Dict = None,
    augmentation: str = "none",  # "none", "balanced", "aggressive"
    dual_channel: bool = False,
    failure_threshold: float = 0.1,
    seed: int = 42
) -> Tuple[SolarFluxDataset, SolarFluxDataset, SolarFluxDataset, Dict[str, Any]]:
```
- Default `split_ratios` to `[0.7, 0.2, 0.1]` if None
- Find and validate .npy files using existing `_preflight_scan_npy`
- Call `assign_files_to_splits(valid_files, split_ratios, seed)` for whole-file assignment
- **Normalization from training files only:** For each training file, mmap and sample values (every 100th) to compute norm params via existing `_compute_norm_params`. Do NOT load val/test files for normalization.
- **Preprocess training files if raw:** For raw .npy structured arrays, convert each to a cube using `_structured_to_cube`, then normalize and save as a temporary .npy cube file (or keep the existing approach of converting in-memory). Actually, since we are mmap-based now, the cube files must exist on disk as `(T, H, W)` shaped .npy files. The raw structured arrays need conversion first. Handle this by:
  - If files are structured arrays (have dtype.names), convert each to cube, save as temp .npy, and use those paths
  - If files are already cubes (no dtype.names, shape is 3D), use them directly
  - Store cube file paths in the dataset
- **BUT** normalization is a problem for mmap: the files on disk are raw, not normalized. The Dataset must either: (a) normalize on-the-fly in __getitem__, or (b) we write normalized files to disk. Option (a) is simpler and avoids disk writes. Add `norm_params` to SolarFluxDataset constructor so __getitem__ can normalize.

  **DESIGN NOTE:** SolarFluxDataset already accepts `norm_params` and `norm_method` parameters (added in 04-01) and applies on-the-fly normalization in __getitem__. This task just needs to pass the computed norm_params and norm_method when constructing SolarFluxDataset instances. Raw files stay on disk unchanged; normalization happens on-the-fly per sample.

- Build index for each split using `build_index()` from dataset.py
- Create SolarFluxDataset for each split, passing `file_paths`, index, and `norm_params`/`norm_method` for on-the-fly normalization
- Training dataset gets augmentation; val/test get `augmentation="none"`
- Return datasets + metadata dict (same structure as before, including normalization params)
