Completely rewrite `solarflare_data/dataset.py`. The new `SolarFluxDataset` class must:

**Constructor `__init__`:**
- Accept parameters: `file_paths: List[str]`, `index: List[Tuple[int, int, int]]`, `t_in: int`, `t_out: int`, `dual_channel: bool = False`, `extreme_threshold: Optional[float] = None`, `norm_params: Optional[Dict] = None`, `norm_method: Optional[str] = None`
- `file_paths` is a list of absolute paths to .npy cube files (each file is shape `(T, H, W)`)
- `index` is a precomputed list of `(file_idx, window_start, aug_type)` tuples
- Store `file_paths` and `index` as instance attributes (both are serializable for spawn)
- Store `norm_params` and `norm_method` as instance attributes (both are serializable dicts/strings)
- Initialize `self._mmap_cache = {}` (populated lazily per worker)
- Do NOT store numpy arrays or mmap handles in __init__

**Augmentation constants (module-level):**
```python
AUG_NONE = 0
AUG_HFLIP = 1
AUG_VFLIP = 2
AUG_ROT90 = 3
AUG_ROT180 = 4
AUG_ROT270 = 5
```

**`_get_mmap(self, file_idx)` method:**
- If `file_idx` not in `self._mmap_cache`, open with `np.load(self.file_paths[file_idx], mmap_mode='r')`
- Return the cached mmap handle
- This ensures each DataLoader worker gets its own file descriptor (safe for both spawn and fork)

**`_apply_augmentation(self, data, aug_type)` static/class method:**
- `AUG_NONE`: return data unchanged
- `AUG_HFLIP`: `np.flip(data, axis=2)` (flip W dimension)
- `AUG_VFLIP`: `np.flip(data, axis=1)` (flip H dimension)
- `AUG_ROT90`: `np.rot90(data, k=1, axes=(1, 2))`
- `AUG_ROT180`: `np.rot90(data, k=2, axes=(1, 2))`
- `AUG_ROT270`: `np.rot90(data, k=3, axes=(1, 2))`
- Always return a contiguous copy (`.copy()`)

**`__len__`:** Return `len(self.index)`

**`__getitem__(self, idx)`:**
1. Unpack `file_idx, window_start, aug_type = self.index[idx]`
2. Get mmap via `self._get_mmap(file_idx)`
3. Slice input: `X_in = mmap_data[window_start:window_start + self.t_in]` -- shape `(T_in, H, W)`
4. Slice output: `Y_out = mmap_data[window_start + self.t_in:window_start + self.t_in + self.t_out]`
5. **Copy immediately:** `X_in = X_in.copy()` and `Y_out = Y_out.copy()` (critical: must copy before modifying mmap view)
6. **On-the-fly normalization** (if `self.norm_params` is not None):
   ```python
   if self.norm_params is not None:
       if self.norm_method == 'asinh':
           X_in = np.arcsinh(X_in / self.norm_params['asinh_softening']) / self.norm_params['scale']
           Y_out = np.arcsinh(Y_out / self.norm_params['asinh_softening']) / self.norm_params['scale']
       else:
           X_in = (X_in - self.norm_params['center']) / self.norm_params['scale']
           Y_out = (Y_out - self.norm_params['center']) / self.norm_params['scale']
   ```
   This keeps raw files on disk unchanged and normalizes per-sample at read time.
7. Apply augmentation: `X_in = self._apply_augmentation(X_in, aug_type)`, same for Y_out
8. Handle dual-channel same as current code (compute extreme channel if enabled)
9. Convert to torch tensors and return `(X_in, Y_out, (file_idx, window_start))`
- Return shape: `(C, T, H, W)` where C=1 (single) or C=2 (dual channel)

**`build_index` module-level function:**
```python
def build_index(
    file_paths: List[str],
    file_assignments: Dict[str, List[int]],  # split_name -> list of file indices
    t_in: int,
    t_out: int,
    stride: int = 1,
    augmentation: str = "none",
    split: str = "train"
) -> List[Tuple[int, int, int]]:
```
- For each file index in `file_assignments[split]`:
  - Load shape only: `mmap = np.load(file_paths[file_idx], mmap_mode='r')`, get `T = mmap.shape[0]`
  - Generate window starts: `range(0, T - t_in - t_out + 1, stride)`
  - For each window_start, add `(file_idx, window_start, AUG_NONE)`
- If `augmentation == "balanced"` AND `split == "train"`:
  - Also add entries with `AUG_HFLIP` and `AUG_VFLIP` for each window
- If `augmentation == "aggressive"` AND `split == "train"`:
  - Also add entries with `AUG_HFLIP`, `AUG_VFLIP`, `AUG_ROT90`, `AUG_ROT180`, `AUG_ROT270`
- Augmentation variants ONLY for training split. Val/test get `AUG_NONE` only.
- Return the index list

**Error handling in `__getitem__`:**
- Wrap mmap access in try/except
- On error: log warning with file path and index, return None
- Document that DataLoader should use a custom collate_fn to skip None samples (but don't implement collate_fn here -- that goes in loader.py)
