**Update `utils/config_validator.py`:**

Add validation rules for the new data fields inside `validate_config()`:

1. `data.augmentation`: Must be one of `["none", "balanced", "aggressive"]`. If missing, default to `"none"`. If old `data.augment: true` is set but `data.augmentation` is missing, log a deprecation warning and set augmentation to `"balanced"` (backward compat).
2. `data.split_ratios`: Must be a list of 3 numbers summing to ~1.0 (tolerance 0.01). Each ratio must be > 0. If missing, default to `[0.7, 0.2, 0.1]`. If old `data.train_split` and `data.val_split` exist but `split_ratios` is missing, convert them: `[train_split, 1 - train_split - val_split, val_split]` and log deprecation warning.
3. `data.stride`: Must be a positive integer. If missing, default to 1.
4. `data.num_workers`: Must be a non-negative integer. If missing, default to 0. Warn if > 0 on non-Linux/non-macOS (untested).

**Update `main.py` `run_training()` function:**

Update the data loading section to use new API:

```python
# Extract new data pipeline config
augmentation = config['data'].get('augmentation', 'none')

num_workers = config['data'].get('num_workers', 0)

```

Update `load_and_prepare_data` call to pass new params:
```python
train_dataset, val_dataset, test_dataset, metadata = load_and_prepare_data(

    t_out=config['data']['t_out'],
    split_ratios=split_ratios,
    stride=stride,
    norm_method=config['normalization']['method'],

    augmentation=augmentation,
    dual_channel=dual_channel,
    failure_threshold=failure_threshold,

)
```

Similarly update `load_preprocessed_data` call.

Update `create_dataloaders` call to pass device, seed, and num_workers:

```python
    num_workers=num_workers,
    device=device,
    seed=seed
)
```

Remove the old `train_split` and `val_split` references. Handle backward compatibility: if `train_split`/`val_split` exist in config but `split_ratios` does not, construct split_ratios from them (same logic as validator).

Remove old references to `config['data']['augment']` -- use `augmentation` throughout.
