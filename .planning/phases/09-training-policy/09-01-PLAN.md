<feature>
  <name>Flare-aware weighted sampling</name>
  <files>
    solarflare_data/dataset.py,
    solarflare_data/loader.py,
    utils/config_validator.py,
    tests/test_data_pipeline.py,
    tests/test_config.py
  </files>
  <behavior>
    build_index flare detection:
    - build_index(paths, assigns, t_in=4, t_out=2, extreme_threshold=5.0) -> (index, flare_flags)
    - len(flare_flags) == len(index) always
    - Sequence with any output pixel > threshold -> flare_flags[i] == True
    - Sequence with input extremes but no output extremes -> flare_flags[i] == False
    - Without extreme_threshold param (None) -> all flare_flags are False (backward compat)
    - Balanced augmentation: all 3 aug variants of same window share same flare flag
    - Val/test splits: flare_flags still computed (for logging), but sampler not used

    build_index backward compatibility:
    - All callers updated: load_and_prepare_data, load_preprocessed_data unpack tuple
    - Return type always tuple (index, flare_flags) regardless of extreme_threshold

    create_dataloaders sampler:
    - When train_flare_flags provided and flare_oversample_weight > 1.0:
      - WeightedRandomSampler created with weights[i] = weight if flag else 1.0
      - num_samples = len(weights) (same epoch length)
      - replacement=True
      - shuffle=False for train_loader (sampler controls order)
    - When train_flare_flags is None or flare_oversample_weight <= 1.0:
      - No sampler, shuffle=True (existing behavior)
    - Val/test loaders unchanged (shuffle=False, no sampler)

    Config cross-check:
    - flare_oversample_weight > 1.0 and augmentation == "none" -> warning logged
    - flare_oversample_weight > 1.0 and augmentation == "balanced" -> no warning
    - flare_oversample_weight absent or <= 1.0 -> no warning
  </behavior>
  <implementation>
    1. Add extreme_threshold param to build_index. Inside window loop, scan output frames
       (mmap[window_start+t_in : window_start+t_in+t_out]) for np.any(frames > threshold).
       Append flag inside the aug_codes inner loop so flare_flags parallels index exactly.
       Always return (index, flare_flags) tuple.

    2. Update all build_index callers in loader.py:
       - load_and_prepare_data: unpack tuple, store train_flare_flags in metadata
       - load_preprocessed_data: unpack tuple, store train_flare_flags in metadata

    3. Add train_flare_flags and flare_oversample_weight params to create_dataloaders.
       Build WeightedRandomSampler conditionally. Use same Generator instance.

    4. Add cross-check in validate_config: read data.flare_oversample_weight and
       data.augmentation, warn if oversample enabled without augmentation.

    5. Update tests: add TestFlareDetection and TestWeightedSampler classes in
       test_data_pipeline.py, add cross-check warning test in test_config.py.
  </implementation>
</feature>
