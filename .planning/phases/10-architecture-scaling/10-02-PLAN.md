    **3. Update _encoder_forward** -- collect all h3 hidden states when temporal attention is enabled:

    Change return signature to include encoder_h3_states (list of per-timestep h states from encoder_conv3):
    ```python
    def _encoder_forward(self, x_prep, T_in):
        h1_seq, h1_states = self.encoder_conv1(x_prep)
        h1_skip = h1_states[0][0]
        h1_seq = self.dropout_enc1(h1_seq)
        h1_down = self.downsample1(h1_seq[:, :, -1])
        h1_down_expanded = h1_down.unsqueeze(2).expand(-1, -1, T_in, -1, -1)
        h2_seq, h2_states = self.encoder_conv2(h1_down_expanded)
        h2_seq = self.dropout_enc2(h2_seq)
        h3_seq, h3_states = self.encoder_conv3(h2_seq)

        # Collect per-timestep h3 states for temporal attention
        encoder_h3_states = None
        if self.use_temporal_attention:
            encoder_h3_states = [h3_seq[:, :, t] for t in range(T_in)]

        return h1_skip, h2_states, h3_states, h1_down, encoder_h3_states
    ```

    **4. Update forward() -- critical changes:**

    a) Update encoder call to receive 5 values:
    ```python
    h1_skip, h2_states, h3_states, h1_down, encoder_h3_states = self._encoder_forward(...)
    ```
    Same for the checkpointed path. For gradient checkpointing: if temporal attention is enabled and checkpointing is on, the encoder_h3_states list should be stacked into a tensor before returning from _encoder_forward (for checkpoint compatibility), then unstacked after. OR simply disable checkpointing when temporal attention is on and log a warning. Choose the simpler approach: stack as tensor, unstack after.

    b) Update decoder state initialization for SA-ConvLSTM 3-tuple format:
    ```python
    if self.use_sa_convlstm:
        # SA-ConvLSTM states are (h, c, m) 3-tuples
        decoder_state2 = [(h2_states[0][0].clone(), h2_states[0][1].clone(), h2_states[0][2].clone())]
        decoder_state3 = [(h3_states[0][0].clone(), h3_states[0][1].clone(), h3_states[0][2].clone())]
    else:
        # Standard ConvLSTM states are (h, c) 2-tuples
        decoder_state2 = [(h2_states[0][0].clone(), h2_states[0][1].clone())]
        decoder_state3 = [(h3_states[0][0].clone(), h3_states[0][1].clone())]
    ```

    c) In decoder loop, after decoder_conv3, add temporal attention:
    ```python
    dec_h3, decoder_state3 = self.decoder_conv3(dec_h2, decoder_state3)

    # Temporal attention: additive context injection (ARCH-07)
    if self.use_temporal_attention and encoder_h3_states is not None:
        # Query the decoder's current hidden state against all encoder states
        dec_h3_frame = dec_h3[:, :, 0]
        context, _attn_weights = self.temporal_attn(
            decoder_state3[0][0], encoder_h3_states
        )
        dec_h3_frame = dec_h3_frame + context
    else:
        dec_h3_frame = dec_h3[:, :, 0]
    ```
    Then use dec_h3_frame (instead of dec_h3[:, :, 0]) for upsample.

    d) Before skip concatenation, add attention gate:
    ```python
    # After F.interpolate size matching:
    if self.use_attention_gate:
        gated_skip = self.attn_gate(dec_up, h1_skip)
        dec_concat = torch.cat([dec_up, gated_skip], dim=1)
    else:
        dec_concat = torch.cat([dec_up, h1_skip], dim=1)
    ```

    e) After output_conv, apply delta_scale:
    ```python
    raw_delta = self.output_conv(refined[:, :, 0])
    if self.delta_scale is not None:
        delta = raw_delta * self.delta_scale
    else:
        delta = raw_delta
    ```
