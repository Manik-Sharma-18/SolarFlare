# Thesis — IIT BHU IDD (Manik Sharma, 21174015)

LaTeX thesis: *Joint-Embedding Predictive Pretraining for Solar Magnetic Winding-Flux Cubes*.

## Build prerequisites

The host system has **no TeX toolchain** at the time of writing. Install one of:

```sh
# Option A — TinyTeX (portable, no sudo, ~300 MB)
curl -sL "https://yihui.org/tinytex/install-bin-unix.sh" | sh
~/Library/TinyTeX/bin/*/tlmgr install latexmk natbib hyperref enumitem \
    titlesec fancyhdr microtype mathptmx amsmath amssymb tikz booktabs \
    geometry caption subcaption ieeetr

# Option B — BasicTeX (needs sudo)
brew install --cask basictex
sudo tlmgr update --self
sudo tlmgr install latexmk natbib hyperref enumitem ...

# Option C — Full MacTeX (~4 GB, sudo)
brew install --cask mactex-no-gui
```

Verify: `which pdflatex latexmk bibtex`.

## Build

```sh
make figures      # regenerate PNG/PDF figures from run.jsonl logs
make              # builds main.pdf (runs latexmk -pdf)
make abstract     # separate Extended Abstract PDF (per guidelines App A)
make clean        # rm intermediates
```

## Layout

- `main.tex` — entry point, `\input`s frontmatter + chapters + appendices.
- `thesis.cls` — custom class (book, 11pt, A4, 1in margins, Times serif, hyperref blue, fancyhdr footer).
- `frontmatter/` — title (outer cream / inner blue board, per IIT BHU §3.2.1), certificate, declaration, copyright transfer, acknowledgement, symbols, preface.
- `chapters/` — 7 chapters (Intro → Background → Data → Architecture → Experiments → Probe → Summary).
- `appendices/` — A hyperparameters, B mask catalog, C clipping audit, D convergence curves.
- `extended_abstract/` — separately-bound 2-page cover-style abstract (guidelines App A).
- `bib/references.bib` — numerical `[n]` citations, 6 subsections (Journals / Conf Proc / Books / Thesis / Tech / Patents).
- `assets/figures/` — auto-generated by `scripts/thesis_figs/*.py`.
- `assets/iitbhu_logo.png` — institute emblem (must supply or run web search).
